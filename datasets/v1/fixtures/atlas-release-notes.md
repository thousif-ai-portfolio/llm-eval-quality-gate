# Atlas Sync 2.4 Release Notes

Atlas Sync 2.4 adds the atlas doctor command, which checks the configuration file,
the cache folder and the network connection, and prints a fix for each problem it finds.

Version 2.4 also makes atlas status show the size of the local cache.
